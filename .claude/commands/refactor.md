# Command: /refactor

When this command is triggered:
1. **Audit**: Review the logic in `backend/db_ai_ops/` or `frontend/src/`.
2. **Decompose**: Split large Flask routes or Vue components into smaller, reusable modules.
3. **Verify**: Ensure imports in `main.js` or `run.py` remain intact.
4. **Document**: Update the `README.md` or `docs/` if API endpoints or environment variables change.
